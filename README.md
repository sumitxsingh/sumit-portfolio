# Sumit Singh Portfolio

A responsive React + Vite portfolio with a dark/light theme toggle, built from the details in the supplied resume.

## Included
- Hero and introduction
- About section
- Skills grouped by category
- Two resume-based project summaries
- Education timeline and relevant coursework
- Contact section using the verified email address
- Responsive mobile navigation
- Dark/light theme toggle (preference saved locally)
- SEO title and description
- Reduced-motion support

## Run locally
1. Install Node.js (LTS recommended).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`, then `npm run preview` to preview the production output.

## Personal details and links
Only the email address and location stated in the resume are used. LinkedIn, GitHub, and project repository URLs were not provided in the resume, so no guessed links are included. Add verified URLs when available.

## Resume download
The provided resume has been copied to `public/resume.pdf`.

## Notes
Google Fonts are loaded from the web. System fallback fonts are included.
